# D-Flex Menu Translation

English and Chinese menu for the D-Flex cafeteria (Business Hall, Dongguk University).

Menu: https://menutrans.pages.dev

## Found a mistake?

Open an issue with the **Translation error** form. Tell us which dish or text is wrong and what it should say.
Issues here are public, so please don't include personal information.

This is an unofficial, student-made translation. For allergies, please ask the cafeteria staff. The Korean original takes precedence.
